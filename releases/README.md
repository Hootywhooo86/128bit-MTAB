## Install

1. On your phone, open this page in GitHub, tap **128bit-1.0.0.apk**, then **Download** (or "View raw").
2. Open the downloaded file. Android will ask to allow installing apps from your browser; allow it once.
3. Tap **Install**.

This build is signed with a development key, so Android may show a Play Protect warning. Tap
"Install anyway". Updates built the same way install over the top and keep your settings.
